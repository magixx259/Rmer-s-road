# C 语言学习 + 嵌入式目标练习包
目标：用 3~5 天学完"能读懂/修改 bench_main.c、写简单电机程序"所需的最小 C。
配套：D:\bench-fw\bench_main.c（155 行真代码）+ 逐行讲解文档。

## 怎么编译运行练习（电脑上）
1. 打开 PowerShell / CMD
2. 编译并运行某个练习：
   compile e03
   （= gcc exercises\e03.c 然后运行）

## 练习顺序（每题对应一个知识点，越往后越贴我们电机代码）
e00 第一个程序（main/printf）
e01 变量与类型
e02 if/else（判断）
e03 for/while（循环，算 1+..+100）
e04 函数（加法器）
e05 宏 #define + 常量
e06 数组（8 字节数据）
e07 位运算：把 3000 拆成高低字节（电机电流帧的核心！）
e08 struct + 指针（模拟电机结构体）
e09 CAN 帧打包（把 4 个电机电流打包成 0x200 帧，复用 FillData 思路）

## 建议节奏
- 每题先自己想 10~20 分钟，再参考答案 answers\aXX.c
- 做之前先看 01-讲解-bench_main.c.md 对应小节

## 验收标准（达到就能支持实验室工作）
1. 能逐行解释 bench_main.c（对着讲解文档）
2. 不看书能写出 e07/e09（位运算 + 打包帧）
3. 知道为什么电流 3000 ≈ 3A（满量程 10000 ≈ 10A）
