# M2006 单电机测试记录

日期：2026-09-10

## 已验证

- 主控：DJI A 板（STM32F427）
- 电机 / 电调：M2006 + C610
- 电机 CAN ID：1
- CAN 接口：CAN1（A 板 PD0 = RX，PD1 = TX）
- 指令帧：0x200 的第 1 路（字节 0、1）
- 反馈帧：0x201
- 控制方式：DR16 右摇杆 Y 轴开环电流控制
- 摇杆上推：代码中的正电流 / 正向
- 摇杆下推：代码中的负电流 / 反向
- 摇杆回中或遥控失联：电流为 0，电机停止
- 结果：遥控通路正常，单电机正反转与停止均已验证

> “正向”是代码定义方向；实际轮子向前还是向后，需要装到对应轮位后再记录。

## 下一步：四轮上车验证

1. 断电接线，确认四个 C610 的 CAN ID 分别为 1、2、3、4。
2. 将底盘架空，逐个发送低电流指令，记录每个轮位的实际转向。
3. 为反向的轮配置软件反向，不通过交换 CAN 线来修正。
4. 四轮独立正确后，再接入麦轮运动学解算与速度闭环。
